PBE v0.9 Capability Workspace

Open PBE_Investor_Demo_v0.8.html in a modern browser. No local server or Node.js is required for this standalone demonstration.

Walkthrough:
1. Choose an example objective or edit the objective text.
2. Select relevant service/capability sources.
3. Click Analyse objective.
4. Review the capability plan, reasoning architecture, and candidate native modules.
5. Click Generate capability spec, then Export JSON to save a structured proposal.

The old “SIMULATED WORKFLOW” header tag has been removed. This remains a standalone interactive browser workspace: the HTML does not call live Composio/OpenRouter APIs, execute external actions, generate production code, or deploy modules. Use the PBE backend separately for configured integration testing.
