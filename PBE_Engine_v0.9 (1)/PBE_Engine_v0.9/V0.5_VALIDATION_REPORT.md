- Unit tests: `pytest -q` passed (4 tests) for sandbox policy and common sensitive-data redaction.

## Checks not completed here

- PostgreSQL/pgvector migrations, Redis/Celery processing, Composio live API calls, OpenRouter live API calls, and Podman sandbox execution require a configured environment and were not live-tested.

## Before using real business data
1. Run `pip install -r requirements.txt` in your own environment.
2. Run `pytest -q`.
3. Apply `infra/postgres/init.sql` to a test database and confirm startup.
4. Test registration/login, workspace isolation, webhook signature + replay rejection, event retries, module approval, and dashboard rendering.
5. Do not execute generated code in the main API process. v0.5 records module approval separately from real deployment.
